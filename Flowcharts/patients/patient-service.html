The Patient Service Manager (PatientService)

Think of this file as the Office Manager. It doesn't store data itself, and it doesn't build the website layout. Instead, it directs traffic, checks paperwork, coordinates tasks, and ensures rules are followed.

The Manager's Trusty Crew

To get anything done, the Manager passes the work down an assembly line of 4 specialists:

1. The Security Guard
Schemas (Zod): Double-checks all incoming user forms. If a phone number is missing or an email is broken, it blocks the entry immediately.
2. The Filing Clerk
Repository: The only one allowed to talk directly to the giant database filing cabinet to save, update, or destroy patient files.
3. The Scribe
Activity Service: Takes silent notes in a history ledger whenever a change happens (e.g., "John Doe was created") for audit safety.
4. The Makeup Artist
Mapper: Cleans up dirty backend database profiles, polishing them into clean data formats ready for the website UI to display flawlessly.
