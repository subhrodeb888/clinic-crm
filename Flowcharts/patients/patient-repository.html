The Database Filing Clerk (PatientRepository)

Think of this file as the Filing Clerk in the basement. It is the only part of the app allowed to open, edit, search, and shred documents inside the master database filing cabinets.

Where the Files are Kept (The Cabinets)

To pull a complete record, the clerk dynamically staples papers together from three separate drawers:

Cabinet 1: Patients
Holds core information like patient names, phone numbers, medical notes, bills, and the ID card number of their assigned doctor.
Cabinet 2: Doctors
A helper drawer containing specific professional medical logs, referenced when checking which doctor belongs to which patient.
Cabinet 3: Users (Auth Names)
The master company directory drawer. The clerk checks this just to grab the doctor's actual real-world display name.
