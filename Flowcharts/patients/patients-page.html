The "Patients" Page Blueprint
Think of this code like a recipe for a digital dashboard. Before showing anything to the user, it gathers information and sets up the layout.
1. THE BRAIN (Data Fetcher)
getPatients() The Request
This goes behind the scenes to the digital filing cabinet (database) and asks for the list of all patients.
▼
patients The Delivery
The raw list of names and records successfully retrieved. This list is now ready to be handed over to the visual elements.
2. THE FRAMEWORK (The House)
DashboardShell Outer Walls
The master frame. It ensures the standard sidebar, navigation menu, and top header are present on the screen.
PageContainer The Room
Creates a neat boundary box with perfect margins and padding so the content doesn't look squished against the edges of the screen.
3. THE VISUALS (The Furniture)
PageHeader The Signpost
Displays the giant bold text saying "Patients" along with a small descriptive label underneath it. It also holds a clickable "Add Patient" button drawer.
PatientsTable The Display Case
Takes that raw list of names delivered by "The Brain" and turns it into a beautiful, neat spreadsheet layout you can actually read and interact with.
